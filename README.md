# 🚀 Projects

## 📈 Project 1 — ATLAS Analytics

### Executive Sales Intelligence Dashboard

🌐 Live Dashboard : https://data-analyst-portfolio-2ghndjjwefjs6maayxh7gh.streamlit.app/

An interactive business intelligence dashboard analyzing sales performance, profitability, customer segments, regional trends, and shipping operations using the Global Superstore dataset.

What it does:

* Tracks executive KPIs including revenue, profit, profit margin, and order volume.
* Analyzes customer segment performance and discount patterns.
* Compares sales and profitability across 13 geographic regions.
* Evaluates shipping costs, shipping modes, and order-to-shipment times.
* Provides interactive filtering, data exploration, and CSV exports.
* Includes 140 automated tests validating calculations and functionality.

Dataset: 51,290 order line items | 25,035 unique orders | 2011–2014

Tech: Python · Pandas · Streamlit · Plotly · NumPy · Excel
