## Projects

### Project 1 — ATLAS Analytics

**Executive Sales Intelligence Dashboard**

Live: https://data-analyst-portfolio-2ghndjjwefjs6maayxh7gh.streamlit.app/

Folder: [`project1-atlas-analytics/`](project1-atlas-analytics/)

Interactive BI dashboard on the Global Superstore dataset: executive KPIs, customer segments, regional performance, shipping logistics, and a data explorer with CSV export. Includes 140 automated tests.

**Run:** `streamlit run project1-atlas-analytics/app_kpi_dashboard.py`

---

### Project 2 — Metric Drop Root Cause Analyzer

Live: https://data-analyst-portfolio-ykkappqtyzqqjeghsd7xmz8.streamlit.app/

Folder: [`project2-root-cause-analyzer/`](project2-root-cause-analyzer/)

Scenario tool for investigating a checkout conversion drop across device, OS, and traffic source.

**Run:** `streamlit run project2-root-cause-analyzer/app_root_cause.py`

---

### Project 3 — Automated Data Cleaning Engine

Live: https://data-analyst-portfolio-a2baphz2hglshyzwp8euiv.streamlit.app/

Folder: [`project3-data-cleaning-engine/`](project3-data-cleaning-engine/)

Upload a CSV, profile missing values and duplicates, apply basic cleaning, and download a cleaned file.

**Run:** `streamlit run project3-data-cleaning-engine/app_data_cleaner.py`
